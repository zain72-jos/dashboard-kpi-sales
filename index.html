Integrasi Google Sheets

Anda dapat menghubungkan Google Spreadsheet Anda secara gratis agar dashboard ini membaca data penjualan riil Anda secara online!

Cara Publikasikan Spreadsheet:

  1. Buka File Google Sheets Anda.
  2. Klik File > Bagikan > Publikasikan ke Web.
  3. Pilih format Comma-separated values (.csv) dan klik Publikasikan.
  4. Salin link CSV yang dihasilkan lalu tempel di bawah ini.
